# SmolVLA 高优任务计划书：从真实视觉服务矩阵到重要边界

2026-09-30。性质：有停止条件的研究执行计划，不是已成立的论文方案。
**项目顺序已调整：** 当前以[主线与优先级计划](MAINLINE_EXECUTION_PLAN_2026-09-30.md)
为准，先补完整远端服务与协作可行域。本文记录已执行的视觉子计划；阶段几何
降为限时数值归因支撑，不再是最高优任务，不继续扩层扫点。
执行时本轮选择的是当时 README 的最高优任务；下文保留当时动机与测量协议。

## 1. 为什么先做这一项

实际双视角离线策略的当前强起点约 2.08 s，其中视觉约 1.108 s、占 53%。
已有单视角 head 并行约 31% 的收益，在双视角融合整相机并发控制下只剩约
4%。动作 CPU/NPU 原生位桥接揭示了“内核更快、表示恢复更贵”的矛盾，但
当前每观测单块只省约 1.2 ms，重要性不足以直接全层铺开。

因此，本轮不预设视觉上存在同一问题，也不再用合成输入的局部收益推演完整
策略。先在实际图像上确认服务时间、数值边界与剩余热点，决定是否值得深入
视觉表示边界。该入口也能回答端云候选的一项前提：本地分支数变化后，最佳
本地并行方式是否变化。

证据：[完整策略重放](SMOLVLA_POLICY_REPLAY_VALIDATION.md)、
[视觉专项](SMOLVLA_VISION_INVESTIGATION.md)、
[优化进展图](SMOLVLA_OPTIMIZATION_PROGRESS.md)。这些旧数据是计划依据，
不能当作本轮已经完成的实验。

## 2. 任务拆解

| 顺序 / 任务 | 动机与目的 | 操作与预期成果 | 风险点与停止条件 |
|---|---|---|---|
| 第一项：实际输入服务矩阵 | 原视觉并行结果主要来自合成图；先确认实际两路图像上的收益与配置关系 | 同一 checkpoint、三帧六张图；比较单分支融合、原生分图全头、head 并行，以及双分支融合并发、head 串行/并发；产出独立会话的完整服务矩阵 | 单分支只做服务测量，不删除策略输入；不同核配置/计时边界不能混算。若实际输入不保留收益，停止推广旧结果 |
| 第二项：数值与状态审计 | 数学等价不能保证融合后舍入一致，不能把更快直接称为合法策略 | 每分支对融合和分图 anchor，检查 head/full 逐层位一致、相机交换/恢复与测量后输出；保存 connector 供后续完整轨迹检查 | 位一致仅适用于已测输入/指定 anchor；特征误差不能替代动作或任务质量。失败则保留诊断，不将候选进入部署 |
| 第三项：实际热点与边界诊断 | 原生位桥接提示布局成本可能抵消更好的计算，但尚未证明视觉有同因瓶颈 | 与正式计时分开，测 12 层累计的 QKV、Attention、输出投影/MLP 和交接；选择有完整上下游证据的一个重要边界继续审计 | 插桩/拆图会改变执行，分项不能替代融合整图。若只有人为坏接口或低重要性的小开销，停止该版本 |
| 第四项：重要边界最小机制实验 | 只有定位到原因，才尝试 CPU 原生位搬运、布局续接或计算分工 | 保留原计算与工作量，比较原融合、现有最佳分区、只改接口的简单替代、候选完整边界；产出配对时延与数值审计 | 不是预先承诺 CPU 赢，也不假定任意 NPU kernel/tile 可实现。机制没有净收益则不建设 runtime |
| 第五项：完整策略与适用范围 | 局部结果必须进入实际重要路径，才能讨论立题 | 通过前述门槛后接统一十步策略；多实际输入、支持的指令形状，再补闭环、隔离内存/能耗与热状态 | 云/仿真访问、编译形状与数值协议是前置风险；没有新闭环前不能宣称任务质量不变 |

第一、二项共享一个测量程序，本轮优先完成；第三项先做低成本分阶段诊断。
第四、五项取决于前面结果，不为“完成计划”而强行实现。任务按证据依赖推进，
不是失败后自动换故事。

## 3. 本轮实验协议

- 数据沿用固定 revision 的 LIBERO-Spatial 演示 episode 11、frame 0/42/83，
  两路图像分别处理；先核验文件 SHA-256 与原 manifest。仍只有一个任务，
  不是跨场景验证、摄像头在线输入或成功率评测。
- 图像预处理遵循 checkpoint 的 `prepare_images`：512×512 resize/pad，
  `pad_value=0`，从 `[0,1]` 转到 `[-1,1]`。预处理在计时前完成并记录哈希。
- 完整视觉为 patch、12 层与 connector。融合控制为修复 patch/零 Mask 后的
  现有图；分图沿用相同真实权重、12 heads、1024 tokens 与目标精度配置。
  服务矩阵不重编译新图、不删头/token、不做近似复用。后续等价几何诊断单独
  编译，设置原图重编译控制，不与服务矩阵样本混池。
- 单分支分别测两个真实相机，不用翻转图代替第二路。单相机融合用 mask7；
  双相机融合并发用已有强配置 mask1/mask2。分图全头是控制，不是新机制。
- 每个输入分别执行两次独立进程会话，每模式每方案 8 次轮换；先暖机。
  测 `resident_compute` 与 `input_compute_output` 两种口径，后者包括 native
  FP32→FP16 存储打包、同步、图运行和 connector FP32 读回；均不含外部
  resize/normalize、图加载与后续策略。
- 两种口径是独立调用，不从中位数差严格推导 I/O 成本；不混池会话/输入，
  不相加阶段中位数。8 次不足以支撑稳定 p95/p99 主张。
- 阶段诊断另外各测 3 次，显式记录为插桩辅助结果；不并入正式吞吐结果。
  使用现有 telemetry 记录频率、温度、driver busy；不将 busy 解释为 MAC
  利用率，不将 SDK 分配字节解释为真实 DDR 流量。
- 两套融合/分图 context 同驻，初始化不计时；因此此次不提供隔离 peak RSS
  或能耗结论。CPU affinity 固定在四个 A76 大核，无并发编译或其他性能实验。

## 4. 决策规则

| 结果 | 下一步 |
|---|---|
| 实际单分支收益成立，双分支强控制吸收多数收益 | 保留服务优势随分支数变化的证据；不等于最佳配置已经切换，也不是端云胜区，不能立刻建调度器 |
| head/full anchor 不一致或相机交换污染输出 | 先定位实现错误；时延结果不能当作合法候选 |
| head/full 一致，但 split/fused 不一致 | 记录误差，后续做完整依赖动作轨迹与任务质量；不称无损部署 |
| 热点转向 consumer，且未发现有证据的表示恢复开销 | 不把通用 FC1 分核自动升为主线；先核查真实编译与上下游原因 |
| 一处重要边界存在可重复的计算/表示代价冲突 | 做第四项最小机制；必须超过完整边界的强简单替代 |
| 净收益只存在于探针，完整控制不改善 | 留为工程诊断，停止该版本；不机械乘层数或跨阶段累加 |

不预设端到端提升比例。重要性按完整关键路径上的实测收益与适用范围判断，
不是规定一个任意百分比后筛选故事。

## 5. 研究逻辑审查

当前更接近 **Technique 候选**，不是已提出并证实的新问题范式。

| 环节 | 本轮内容与证据状态 |
|---|---|
| 背景 | RK3588 上实际双视角 SmolVLA 视觉仍占约一半推理时延，影响响应；不以摄像头采集/预处理本身是最大耗时为动机 |
| 局限一 | 单视角并行收益被双视角强配置吸收，独立算子或单分支最优不等于完整工作负载最优；本项目已有测量支持 |
| 局限二 | 更好的内核几何可能引入昂贵表示交接；动作边界已测，视觉是否存在仍是关键缺口 |
| 目标 | 在实际视觉关键路径上，验证并行与表示交接能否共同决定一个优于现有强控制的执行方式 |
| 挑战一 / 方法一 | 多并行维度竞争且测量易失配 → 实际单/双分支同口径服务矩阵 |
| 挑战二 / 方法二 | 数值与状态污染可能伪造加速 → 分 anchor 的逐层/交换/恢复审计 |
| 挑战三 / 方法三 | 拆图可能制造而非发现痛点 → 完整上下游边界与简单替代对照 |
| 预期研究产物 | 服务/数值矩阵、重要边界因果解释、条件成立后的最小机制与完整策略验证；均不是提前承诺的论文贡献 |

局限→目标、目标→挑战、挑战→测量任务的映射成立；但“方法→论文贡献”
在初始规划时仍有两项重大缺口：视觉同因限制未证实，完整策略差异化收益未证实。
因此本轮可执行，不具备直接撰写贡献或 Introduction 的条件。已有布局优化、
异构推理与端云部署的创新边界仍需在机制成立后专项对照，不能以“没见过”
证明新颖性。

## 6. 执行记录与复现

完整执行见 [实际服务与阶段几何报告](SMOLVLA_VISION_SERVICE_VALIDATION_2026-09-30.md)。

| 计划任务 | 本轮状态 | 实际产出 |
|---|---|---|
| 实际服务矩阵 | 完成 | 三帧双相机、两会话、十方案、每模式八次；实际单视角 head 收益约 32.4%–32.8%，双视角 head 串行相对融合并发约 6.2%–6.3% |
| 数值/状态审计 | 分 anchor 审计完成，原融合质量 gate 未关闭 | 十二层 head/full、相机交换/恢复和测后检查通过；分图与融合 connector 仍不同，不能称无损策略 |
| 热点/边界诊断 | 完成当前有界范围 | 原实际末层没有昂贵恢复矩阵；MLP 仍大。整段二维表示令归一化将 H 转为 batch，后续 FC1 明显变慢 |
| 最小机制 | 几何反事实已测，原数值 gate 失败 | 归一化后拆图、仅改 MLP 几何：约 18.9 → 15.8–16.0 ms，额外调用计费；对 flat split 位一致、对原 consumer 不一致。单图 reshape 简单替代仍慢，编译后移到 Norm 之前 |
| 完整策略/范围 | 未开始新候选集成 | 先保持原融合数值，不乘十二层；GPU/仿真现有环境访问已恢复，尚无新云时延或闭环结果 |

**该子计划内部的可选续验：保持原融合数值的阶段几何。** 它不再定义项目
下一项任务，初轮数值归因预算上限为 1–2 个工作日。动机是阶段几何的实测
反转，不是预设 CPU 赢。目的：定位 Norm/残差/FC2 的差异，核查末端 ConvAdd
退融合与舍入，寻找保住 B=1 二维 MLP 且保住原数值协议的接口。预期交付：
实际中间量审计、强简单控制与完整 consumer 配对时间；不预设实现可行。
若必须放宽数值协议才有收益，暂停部署候选。该 gate 通过也不自动扩层；还须
由主线完整时间线证明重要性，才考虑代表层、十二层和完整策略。既有工作差异
仍待证明。

整段几何、归一化后拆图、单图局部 reshape 各有独立正式会话，实际六张图、
每方案四十次。它们验证不同问题，不把会话/图数不同的样本混成累计加速链。
新柱状图同时标出了更快路径的原数值 gate 失败，避免只展示有利时延。

大型图、实际图像与 connector 二进制保留在本地 cache/板端，Git 只存脚本、
manifest、测量 JSON 和解释文档。本轮更新 README、候选表并直接提交推送。

2026-09-29。定位：研究决策记录，不是完整 C17 加速或闭环成功率结果。

## 2. 完整策略的强基线

三种 action 路径共享相同视觉控制：已修复 patch/零 mask 的完整融合视觉图，
两套独立 I/O、mask1/mask2 整相机并发，随后原 32 层 RKNN prefill。
视觉输入打包/同步、线程提交、connector 读回均计入；并发结果在实际帧上经
串行、相机交换、恢复输入检查逐位通过。

这不是原融合视觉图与 packed/head 分图之间的逐位保证。此处故意不用尚有
融合舍入差异的视觉分图方案作为质量已通过的完整策略。此前双视角更快约
4%-6% 的 head 方案仍需要独立质量门槛，因此本控制不是所有数学等价实现的
绝对最优。不能忽略该强替代方案，更不能将旧 31% 单视角收益反复计入。

完整策略时延中位数，ms，包含模型内图像准备、视觉、prefill、条件准备、
十步 action 及 CPU Euler。不含外部 checkpoint preprocessor、传输、仿真与
动作 postprocessor，也不含图/context 初始化。

这不是新论文机制。C06 相对 resident 的完整策略中位数再低 **2.43%-2.78%**，

每帧检查十个 velocity、所有 FP32 latent 和最终完整 latent；三个计划逐位一致，
切回第一帧亦一致。这里是与共享视觉/prefill 后的原 RKNN 目标路径一致，

251-255 ms、十步 action 706-719 ms、其余约 20-21 ms。按各自完整时延均值
计，视觉 **52.68%-53.11%**，action **33.84%-34.23%**，prefill 约 12%。

## 3. C17 接观测驱动输入后是否还成立

从 strong2 的原 Lite action 路径捕获实际 RKNN prefill K/V 与十步依赖
轨迹中的 suffix。用原 layer-0 ONNX、关闭优化的 CPU FP32 ORT 重建
layer-1 输入 hidden。因此它是**观测驱动的条件/轨迹重放，不是 NPU 内部
hidden 捕获，也没有让 C17 输出反馈进 Euler**。

仍是 Q/RoPE/cross-Attention/O/residual 边界，不含 MLP。三组十个 hidden
分别测试原目标、head 强对照与 CPU 双向位桥接；30 个步骤的两个候选都与
原目标逐位一致。每组两个计时模式轮换 60 次，每序列准备/同步/读回计入，
公共 raw prefix 打包等额排除。

| 输入帧 | head 强对照中位数 | 双向位桥接中位数 | 中位数降低 | 逐轮胜数 |
|---|---:|---:|---:|---:|
| 0 | 11.723 ms | 10.521 ms | 10.26% | 60/60 |
| 42 | 11.740 ms | 10.529 ms | 10.32% | 60/60 |
| 83 | 11.724 ms | 10.531 ms | 10.18% | 59/60 |

局部增量约 **1.2 ms/观测/一个 cross block**，只占上述完整策略约 0.058%。
即便假设 16 个 cross 层都能取得同样的 *相对 head 并行* 增量，机械外推也仅约
19 ms、不到完整策略的 1%。这不是上界，也不是已测整图收益：当前完整 C06
图没有集成逐层 head 拆分，图间交接与融合也会改变，不能把这些数字直接相加。

**判断：C17 局部机制没有被真实条件推翻，但仅靠当前块不够支撑重要性。**
保留机制，暂不铺开 32 层；后续须证明另一类重要边界/形状也受同一原因限制，
或者完成超过最强整图控制的真实集成，而不是把局部 10% 写成 VLA 的 10%。

证据：[观测驱动的 C17 重放](../results/smolvla_libero/policy_replay_probes/cross_replay_session1.json)。

## 4. 尾延迟被定位到哪里

另对原合成条件做三轮诊断，每种模式每轮 500 次、十次消费。前两轮使用原
library，第三轮为带逐步/worker 时间线的诊断 library；不混池，插桩不能当免费。

| 会话 | head p50/p95/p99，ms | 位桥接 p50/p95/p99，ms | 逐轮胜数 |
|---|---|---|---:|
| tail1 | 11.449 / 15.984 / 16.338 | 10.244 / 15.492 / 15.587 | 486/500 |
| tail2 | 11.474 / 13.988 / 15.889 | 10.257 / 13.009 / 15.119 | 480/500 |
| trace | 11.519 / 15.957 / 16.369 | 10.268 / 13.960 / 15.581 | 489/500 |

慢尾里位桥接每步打包/恢复仍约 20/18 us；worker 唤醒中位数约 4 us，
全部样本最大约 39 us。相反，producer 每步从约 360 增到 594 us，consumer
从约 178 增到 338 us，compact worker 的最长 NPU 调用从约 350 增到 468 us。
不是位复制或常驻线程启动成本主导此次慢尾。

频率采样固定、温度低于约 39 C，未见持续降频/高温。最慢 5% 中有大量
没有非自愿切换的调用，但这不排除短时调度或内核唤醒等待。
**目前定位到同步 NPU 调用路径，不进一步归因为硬件 kernel、驱动、QoS 或
某一功耗机制。** 之前 S13 p95 反向的记录保留；本轮更大的尾部样本有改善，
仍不是跨热状态/部署场景的尾延迟保证。

证据：[尾部分项分析](../results/smolvla_libero/cross_followup_probes/tail_audit.json)。

## 5. 无损端云边界的反证

同样六张真实记录图像。原 256x256 RGB 还原为 uint8 后可逐位重建输入 FP32
图像；PNG/zlib 编解码均做无损还原检查。connector 来自上述原生融合 NPU 图。
FP16 存储再恢复 FP32 对这六个输出逐位相同：它们原本就是 FP16 NPU 输出的
FP32 解包，不是新降低精度。**不能推广到任意云端 FP32 connector。**

| 每视角表示 | 实际字节数 |
|---|---:|
| 原 256x256 RGB uint8 | 196608 |
| 无损 PNG | **58270-67358** |
| uint8 zlib | 68284-81947 |
| connector 原 FP32 | 245760 |
| connector FP32 zlib | 146037-146469 |
| 逐位可恢复的 connector FP16 | 122880 |
| 上述 FP16 zlib | **113842-113986** |

因此，“提特征以后字节更少”的默认动机在这些观测上不成立：PNG 约 57-66 KiB，
紧凑无损特征仍约 111 KiB。RK A76 上 PNG 编码约 17-22 ms/视角、解码约
1.75-2.16 ms；FP16 zlib 编码约 5.1-5.3 ms。它们是五次 codec 微测的中位数，
不是网络服务时延。两种 codec 都是当前控制，不宣称已穷尽无损编码器。
无损 PNG 相对于数据集中解码出的图像无新增损失，不追溯其原始录制编码质量。

证据：[明确 affinity 的无损 payload](../results/smolvla_libero/policy_replay_probes/lossless_payload_a76.json)。

## 6. 下一步押什么，不押什么

1. **不押 C17 全层铺开。** 先保持当前结论，将新实验预算移回占约 53% 的视觉
   关键路径；C17 用于探索另一处同因边界，不以“16 倍局部收益”立项。
2. **C04 可细化为一个待证伪假设：卸走一条相机分支，会不会改变端侧最优并行维度？**
   原双视角适合整相机并发；仅剩一个本地相机时，可转为 head 并发。端云分工
   可能同时改变端侧执行配置，而不只是减少固定比例的工作量。此前单视角
   775->532 ms 是合成输入、且 split/fused 非逐位一致的证据，不能直接当作本轮
   合法服务时间或完整策略质量保证。下一关是相同实际输入下的 branch 服务矩阵
   与数值门槛，而不是现在就建自适应 runtime。
3. **端云先算可行域。** 全云允许逐相机上传/编码/计算重叠，不能用“全部上传
   完再开始算”的弱基线。分别测上/下行、云排队、单分支 GPU 与完整 GPU、端侧
   后半程及返回特征。必须存在同时击败优化全端和流式全云的区域，并让
   最强静态分工/静态 core 配置作对照；否则停止。网络受限和异构都不是免费动机。
4. **C08 仍只做阶段诊断。** 视觉热点已确认，但没有证据证明 CPU 归一化比 NPU
   更快。先测实际 QK/softmax/PV 与交接成本，不把尾延迟线索硬包装成 CPU/NPU
   切换机制。若只有一个固定调度小收益，按工程项处理。

本轮未更新部署图、未做后训练/近似复用，未启动端云服务或闭环评测。
